# .agent (Single-Agent Systems)

This directory contains workflows, skills, and tools intended for **Single-Agent Systems**.

## Scope & Purpose
- **Scope:** Focused on specific, narrow tasks.
- **Autonomy:** Acts as a direct tool. It follows step-by-step instructions and typically requires human direction or a strict pipeline.
- **Best For:** Automating repetitive, predictable jobs like extracting data from a specific document, auditing accessibility for a component, running tests, or resolving branch conflicts.

## Structure
- `workflows/`: Step-by-step pipelines for specific narrow tasks.
- `skills/`: Protocols and capabilities the agent can use independently.
