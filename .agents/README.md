# .agents (Multi-Agent Systems)

This directory contains orchestration workflows intended for **Multi-Agent Systems**.

## Scope & Purpose
- **Scope:** Handles complex, cross-functional problems.
- **Autonomy:** Utilizes an orchestration layer where different specialist agents reason, plan, and collaborate to achieve a broader goal (e.g., one agent researches a topic, another summarizes it, and a third codes).
- **Best For:** Open-ended, ambiguous workflows like full software application development, complex supply chain analysis, or in-depth environment provisioning.

## Structure
- `workflows/`: Orchestration pipelines that connect multiple specialized workflows or agents to accomplish a large-scale goal.
- [pnpm-rules.md](file:///d:/Study/Programming/Projects/finalsv2/finals-qb/.agents/pnpm-rules.md): Rule document dictating the use of pnpm in all executions.
