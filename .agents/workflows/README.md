## Executing a Workflow

When executing a workflow:
1. Locate the workflow `.md` file in this directory.
2. Read the prerequisites and dependencies to ensure the system is ready.
3. Follow the **Step-by-Step Execution Protocol** sequentially.
4. Execute the verification tests to validate success before completion.
