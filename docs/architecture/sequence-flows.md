# Sequence Flow Diagram (Dimension 5)

> Generated by Graphify on June 8, 2026. Last updated: June 8, 2026.

## Diagram

```mermaid
sequenceDiagram
  actor User
  participant UI as HomeScreen/Game UI
  participant GE as GameEngineProvider
  participant AP as AchievementProvider
  participant SP as StatsProvider
  participant LS as Browser LocalStorage

  User->>UI: Select Mode & Click Start
  UI->>GE: Initialize (shuffled pool, timers, config)
  GE-->>UI: Render First Question
  
  loop Active Quiz Loop
    User->>UI: Click Option & Submit
    UI->>GE: SELECT_OPTION & REVEAL_ANSWER
    GE-->>UI: Update Phase (Reviewing), Show Feedback, Log Incorrect to CheatSheet
    User->>UI: Click Next
    UI->>GE: NEXT_QUESTION
    GE-->>UI: Render Next Question
  end

  GE->>GE: Game Ends (Phase = complete)
  UI->>AP: Trigger onGameComplete(state, runs)
  AP->>LS: Load current achievements
  AP->>AP: Evaluate unlocked conditions
  AP->>LS: Save unlocked achievements
  AP-->>UI: Trigger Toast Alert (unlocked achievements)
  
  UI->>SP: Append RunRecord & Update Streaks
  SP->>LS: Save new runs & stats (50-run limit)
  SP-->>UI: Render Results Panel
```

## Analysis Notes

- **Optimizations:** Async execution of achievement checking and localStorage saves prevents UI lag at the end of a session.
- **Race conditions:** `achievementsFiredRef` is used as a guard to ensure `onGameComplete` fires exactly once per run.
- **Offline-First:** No external server calls are made during the entire loop, ensuring absolute privacy and zero lag.
