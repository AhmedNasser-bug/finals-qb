## Analysis Notes

- **Critical paths:** The state flow between `StatsProvider`, `AchievementProvider`, and `StorageAdapter` ensures strict subject isolation for runs, streaks, and achievements.
- **Risk areas:** Removing Clerk requires `SafeAuthProvider` to maintain backwards-compatible auth state (`userId: null, isSignedIn: false`) so components consuming auth never throw.
- **Stale/dead code suspects:** Clerk middleware and packages `@clerk/nextjs` / `@clerk/ui` are deprecated and scheduled for complete removal.
