🎯 **What:**
Removed the leftover `console.error('Mermaid render error:', err);` statement in the generated HTML from both `generateSubjectHtml` and `generateSubjectSolvedHtml` functions in `lib/subject/subject-sharing.ts`.

💡 **Why:**
These error logs are printed into the client-side browser console when Mermaid diagrams fail to parse or render. Since there is already a robust fallback UI (the `[Diagram Render Fault]` box) that clearly displays the error directly in the DOM, the raw `console.error` is redundant noise in production. Removing it improves code health and cleanliness without altering user-facing behavior.
