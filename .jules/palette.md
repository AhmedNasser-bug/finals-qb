
## 2026-06-17 - [Mobile Navigation Accessibility]
**Learning:** Bottom mobile navigation bars with heavy abbreviation need descriptive aria-label and title attributes to maintain accessibility without compromising visual design. The <nav> tag should also be used instead of <footer> for correct semantic landmarks.
**Action:** Use <nav aria-label='...'> and add 'aria-label' and 'title' to icon/abbreviated buttons to improve screen reader experience and usability.
