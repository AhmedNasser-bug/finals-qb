## 2026-08-24 - [Optimize string iteration parsing]
**Learning:** In JavaScript/V8, accessing `str[i]` creates and allocates a new one-character string in memory for every single character iteration. By using `.charCodeAt(i)`, the loop works with integers instead, which avoids thousands of unnecessary object allocations during string parsing. This significantly reduces Garbage Collection (GC) pressure and CPU cycles on large JSON strings.
